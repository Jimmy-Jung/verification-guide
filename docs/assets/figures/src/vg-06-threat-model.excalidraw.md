## Visual Brief

- 핵심 주장: 믿을 수 없는 입력은 신뢰 경계에서 입력 제한을 먼저 지나고, 링크·스크립트·외부 요청·네이티브 엔진 경로마다 방어와 검증이 따로 붙는다.

- 상태 변화: 원문 → 제한된 입력 → 경로별 처리
- 등장 주체: 입력 원천 · 입력 제한 · 출력 경로 4개
- 상황 Caption: 위협 모델
