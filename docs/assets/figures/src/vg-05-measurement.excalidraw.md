## Visual Brief

- 핵심 주장: 실기기의 Release 앱은 구간 표시를 남기고, 조작은 UI 자동화 또는 자동 재생이 맡으며, 프로파일러는 밖에서 관찰만 하고, 호스트는 빌드·설치·결과 회수·커밋 기록을 맡는다.
- 시작과 끝: 빌드에서 결과 기록까지
- 주 흐름: 호스트 → 기기(명령), 기기 → 호스트(회수)
- 상태 변화: 소스 → 설치된 앱 → 트레이스 → 기록
- 등장 주체: 앱 · 조작 · 프로파일러 · 호스트
- 상황 Caption: 측정 구성
