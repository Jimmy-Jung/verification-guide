## Visual Brief

- 핵심 주장: 검증은 계획→실행→해석→보고 순서로 진행하고, 해석에서 측정 방법이 의심되면 실행으로 돌아가며, 보고의 남은 조건은 다음 계획의 입력이 된다.
- 시작과 끝: 계획에서 보고까지, 다시 다음 계획으로
- 주 흐름: 왼쪽에서 오른쪽, 되돌아감은 아래 파선
- 상태 변화: 질문 → 측정값 → 판단 → 보고서
- 등장 주체: 계획 · 실행 · 해석 · 보고
- 상황 Caption: 검증 단계
